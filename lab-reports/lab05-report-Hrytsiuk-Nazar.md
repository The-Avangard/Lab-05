## Мета роботи

Розробити REST API на Flask для роботи з товарами й замовленнями, повертати дані та помилки у форматі JSON, документувати маршрути й перевірити їх тестами. У проєкті реалізовано всі три рівні: базові операції API, документацію Swagger, версії `v1` і `v2` та розширену валідацію.

## Особистий внесок

- реалізував версійовані маршрути API товарів для `v1` і `v2`;
- додав Swagger-описи операцій товарів, параметрів, схем запитів і відповідей;
- розширив Postman-колекцію позитивними та негативними сценаріями для товарів і замовлень;
- виправив формат URL у нових Postman-запитах і оновив підсумковий скриншот після успішного запуску колекції.

## Реалізоване API

API працює з товарами та замовленнями у SQLite. Для кожного ресурсу доступні версії `v1` і `v2`; загалом задокументовано 18 маршрутів. Операції з товарами охоплюють список із пошуком і фільтрацією, перегляд за ID, створення, повне оновлення та видалення. Вхідні поля перевіряються, зокрема категорія, назва та ціна.

Документація з описами маршрутів і схемами доступна через Swagger UI за адресою `/apidocs/`. Детальна таблиця ендпоінтів наведена у [README проєкту](../README.md).

## Труднощі та висновки

Під час підготовки колекції виникла проблема з URL змінної `base_url`: некоректно сформована адреса спричиняла помилки з’єднання. Після виправлення адрес запити обох версій виконалися, а колекція завершилася без помилок.

Під час роботи я закріпив навички створення Flask-маршрутів, перевірки вхідних даних, опису API у Swagger і тестування HTTP-запитів у Postman. Також перевірив, що однакова функціональність доступна через версії `v1` і `v2`.
