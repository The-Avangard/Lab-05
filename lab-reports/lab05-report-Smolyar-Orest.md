## Мета роботи

Розробити REST API на Flask для роботи з товарами й замовленнями, повертати дані та помилки у форматі JSON, документувати маршрути й перевірити їх тестами. У проєкті реалізовано всі три рівні: базові операції API, документацію Swagger, версії `v1` і `v2` та розширену валідацію.

## Особистий внесок

- реалізував версійовані маршрути API замовлень для `v1` і `v2`;
- додав операції отримання списку замовлень і замовлення з позиціями, створення замовлення та оновлення його статусу;
- задокументував операції замовлень у Swagger, включно зі схемами та відповідями з помилками;
- перевірив роботу сценаріїв замовлень у складі спільної Postman-колекції.

## Реалізоване API

API працює з товарами та замовленнями у SQLite. Для кожного ресурсу доступні версії `v1` і `v2`; загалом задокументовано 18 маршрутів. Операції із замовленнями охоплюють отримання списку з фільтром статусу, перегляд одного замовлення разом із позиціями, створення замовлення та зміну статусу. Дані й помилки повертаються у форматі JSON; некоректні запити та невідомі ресурси обробляються відповідними HTTP-кодами.

Документація з описами маршрутів і схемами доступна через Swagger UI за адресою `/apidocs/`. Детальна таблиця ендпоінтів наведена у [README проєкту](../README.md).
